OnStove

Open-source Spatial Clean Cooking

OnStove is a geospatial cost-benefit tool for clean cooking access planning. Each Starter Data Kit is a country package of the geospatial and socio-economic input layers needed to run an OnStove analysis. Select a country to download its complete data kit.

Country kits are large (roughly 400–550 MB). If Google shows a “can’t scan for viruses” page, click Download anyway to proceed.
